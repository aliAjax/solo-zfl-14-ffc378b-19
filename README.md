# 家庭维修协同台

端口规划：dev `5114` / preview `6114`

按「房产 → 房间 → 设备」建立档案，再按设备报修并协同流转。数据保存在
浏览器 localStorage（键：`zfl-14-home-repair:v2`），刷新/重开不丢失。

## 功能

- **档案**：房产、房间、设备三级档案，设备归属房间，房间归属房产。
- **报修**：按设备发起工单，填写问题、优先级（紧急/高/中/低）、计划完成日、预计费用。
- **流转**：待确认 → 处理中 → 待验收 → 已验收；待确认/处理中可取消；
  验收不通过必须填原因并退回处理中，可重新提交验收。非法跳跃被禁止。
- **维修记录**：仅处理中可记录实际费用、耗材（名称/数量/单价）和处理结果，
  支持多条记录，实际费用自动累计。
- **列表筛选**：状态、优先级、房产、设备、只看逾期、关键词（问题/设备/房间/房产/处理结果）
  可任意组合；排序支持紧急度、预计费用升降序、计划完成日临近。
- **统计**：未完成数、逾期数、待验收数、本月实际支出（按当月维修记录）、
  未完成预计费用；设置月预算后超支顶部告警。
- **健壮性**：
  - localStorage 坏数据（非法 JSON / 结构损坏 / 非法字段）自动回退空数据或剔除坏行；
  - 报修使用一次性提交令牌 + 提交中禁用按钮，双击/重试不会产生重复工单；
  - 所有表单异常输入给出字段级红色提示，不落任何脏数据。

## 常用命令

```bash
npm install
npm run dev        # 开发
npm run build      # 生产构建
npm run test       # vitest 单元测试（状态机/筛选/统计/存储/防重复）
npm run e2e        # playwright 浏览器自动化（报修/流转/验收退回/筛选统计/坏数据）
```

### 无 root 环境下安装 Playwright 浏览器依赖

`npx playwright install --with-deps chromium` 需要 apt 权限。无 root 时可用：

```bash
bash scripts/install-browser-libs.sh   # 用 apt-get download + dpkg -x 解包到 .playwright-libs/
```

`playwright.config.js` 会自动把 `.playwright-libs/root` 下的库加入
`LD_LIBRARY_PATH`，无需手动设置环境变量。
